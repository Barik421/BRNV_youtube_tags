BRNV YouTube Tags

Вставте YouTube Data API v3 key. Ключ зберігається локально у Chrome через chrome.storage.local.

Як отримати YouTube API key

  1. Відкрити https://console.cloud.google.com/
  2. Створити новий проєкт BRNV YouTube Tags.
  3. Відкрити APIs & Services → Library.
  4. Знайти YouTube Data API v3.
  5. Натиснути Enable.
  6. Відкрити APIs & Services → Credentials.
  7. Натиснути Create Credentials → API key.
  8. Скопіювати ключ.
  9. У налаштуваннях ключа дозволити лише YouTube Data API v3.
  10. Вставити ключ у налаштування розширення та зберегти.

OAuth і вхід через Google не потрібні. Реальний API key не можна додавати в GitHub або вставляти в код розширення.
