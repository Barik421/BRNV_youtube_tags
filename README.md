# BRNV YouTube Tags

BRNV YouTube Tags is a Chrome extension that shows the tags of a YouTube video directly below the video page.

The tags block is compact by default and can be expanded to show every tag with line wrapping. All tags can be copied at once, including tags hidden in the collapsed preview.

The popup lets you paste a link to another YouTube video and fetch its tags without leaving the current tab.

Tag data is retrieved through the official YouTube Data API v3. The YouTube API key is saved locally in Chrome storage, is not hard-coded, and should not be committed to GitHub.

The extension does not use a server and does not collect user data.
